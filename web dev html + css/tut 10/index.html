attribute = loop , autoplay, controls , muted, preload= "none, metadata, auto
none = this is a default value it indicates the browser should not preload the audio file at all the audio file will only start downloading when the user initiates playbacks .
metadata = this value tell the browser to preload the audio file such as its duration and basic information about audio . this can be useful if you want to display the audio duration to the user without fully loading the audio data .
auto = this value instruct the browser to preload the entire audio as much as possible without delaying the loading of other important page content . the browser will try to load the audio file in the background so that its ready to play when the user decides to start it .

i frames

They allow you to embed another HTML page within your current page.


iFrames offer a variety of use-cases:
Content Isolation: iFrames allow you to isolate third-party content, which can improve security.
Modularity: Easily embed external plugins, widgets, or content.
Resource Separation: Content within an iFrame can load separately from the rest of the page.
